The system

An inverted rotary pendulum.

Consider the orbiting figure below. A base motor applies a moment M(t) about the vertical \vb{E}{}_3, spinning a rotary arm (bar B, angle \theta). At the arm's tip the pendulum (bar A, angle \varphi) swings freely. Gravity in the system acts on the -\vb{E}{}_3 direction. Viscous drag and dry friction were treated to be negligible in this problem.

The objective here is to keep this pendulum upright (\varphi = 0), however, this position is unstable. Given this, is it possible that the applied moment could stabilize the pendulum in this position?

In order to investigate further, the full derivation of the theory used and the software implementation is on the theory page. If you would like to see the system in action, you can open the simulator page and see whether the pendulum would balance given different parameters.
